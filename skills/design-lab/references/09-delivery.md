# 09 · 智能体生产交付保障

> 目标：保证设计的智能体"真实环境能交付、上线后不翻车"。交付的前提是**能度量**。
> 对应 `02` 模式 11/13/17/18 和 `03` 问题映射。

## 1. 评估（上线前的质量门槛）

### 1.1 评估集（黄金用例）
- 覆盖所有 BDD 场景（主流程/异常/边界），每个用例 = 输入 + 期望结果。
- 至少 20-30 条起，含**对抗用例**（幻觉注入、越权尝试、注入攻击）。
- 真实数据抽样补充，避免"自测全过、线上翻车"。

### 1.2 双轨策略（support-agent 验证）
- **mock 规则引擎**：确定性、可断言，跑 CI 全量。
- **真实 LLM**：跑关键场景，验证工具协议契约（schema 恒定）。

### 1.3 指标
- **检索质量**（RAG 类）：Context Precision@k / Recall@k / MRR / NDCG / Hit Rate@k。
- **生成质量**：Faithfulness（每条声明有依据）/ Answer Relevancy / Completeness（LLM 当评委）。
- **幻觉防线**：置信度阈值（如 0.7）+ 注入幻觉用例的拦截率。
- **覆盖率**：状态机全流转、权限、工具协议 ≥ 80%。

## 2. 测试

| 层 | 测什么 | 工具 |
|----|--------|------|
| 单元 | 工具函数、检索、切块、提示词构建 | pytest / vitest 等 |
| 集成 | API 端点、数据库、SSE、工具注册表 | pytest + 真实 DB |
| E2E | 用户主流程（提问→工具→回答→HITL→工单） | Playwright 等 |
| 契约 | 工具 schema 恒定、状态机非法转移拒绝 | 契约测试 |
| 多 agent 组合 | 协调者+worker 编排（mock worker 注入失败/冲突/全文回传，验证超时兜底与仲裁） | 契约测试 |

关键测试法：**故意注入幻觉声明，验证拦截器能抓到**（如"爱因斯坦 1905 年发明 RAG"）。

## 3. 护栏（安全内置，不是后期补）

- **输入校验**：所有外部输入过 schema，fail fast。
- **权限 fail-closed**：新工具默认敏感；单调权限收窄（子 ⊆ 父）。
- **输出过滤**：PII 脱敏、敏感内容拦截、长度截断。
- **对抗测试**：用攻击集压测护栏（prompt 注入/越权/诱骗），参考 ASTRA 140 次攻击思路。
- **密钥管理**：环境变量/密钥管理器，不硬编码；泄露即轮换。
- **审计日志**：工具调用、状态变更、HITL 全部落审计。

## 4. HITL（敏感操作人工确认）

- 标记 `sensitive=True` 的工具：模型发起 → UI 确认弹窗 → 确认后执行。
- 规则：确认前不落库；防重复提交；防越权（403）；只对高风险用，别滥用。

## 5. 异常恢复

- **超时 + 最大步数**：单轮/总循环上限，防死循环。
- **指数退避重试** + 最大次数 + 熔断。
- **分层降级**：真实 LLM → mock/缓存 → 简化响应。
- **分层取消**：用户取消级联取消子任务 + 确定性清理。
- **状态机 + 转换日志**：可回放定位。
- **乐观恢复**：失败回退安全点。

## 6. 可观测性（上线后）

- **日志**：请求/工具调用/错误/审计，结构化（含 trace_id）。
- **指标**：延迟分位、token 用量、成本、成功率、幻觉拦截率、HITL 触发率。
- **Trace**：一次用户请求跨所有组件/工具调用的完整链路（OpenTelemetry）。
- **告警**：关键进程 watchdog、错误率阈值、成本超预算告警。

## 7. 事故复盘（SRE post-mortem）

每次事故按 SRE 手册骨架复盘：Summary → Impact → **Root Causes 与 Trigger 分开** → Detection → Timeline → Action Items（落到代码）→ Lessons（做对/做错/运气）→ 教训回踩坑库（04）。
⚠️ 关键判断：**根因 ≠ 触发点**——Trigger 是导火索，Root Cause 是让导火索能点着火的系统性缺陷；five whys 挖到可行动项为止；blameless：不追责人，只修系统。
> 来源：SRE Book postmortem 模板（sayyidrizvi-work/SRE-Postmortem-Templates）+ ai-agent-incidents（委派闭环、单点守卫、配置变更健康验证、don't fake it）。
